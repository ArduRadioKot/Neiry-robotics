# Меканум-робот в Gazebo

- `world.sdf` — площадка и робот для Gazebo.
- `model.py` — математическая модель.
- `trajectory.py` — настройки круговой траектории или восьмёрки.
- `simulation.py` — управление роботом в уже открытом Gazebo.
- `Видео_симуляции_Gazebo.mp4` — запись предыдущего опыта с прямыми углами.
- `assets/` — модели колёс и SDF с параметрами для матмодели.

Для работы нужны Ubuntu в WSL2, WSLg, ROS 2 Jazzy, Gazebo Harmonic и Python-пакеты numpy и scipy. Модули `gz.transport13` и `gz.msgs10` должны быть доступны в Ubuntu.

В Ubuntu перейдите в эту папку и откройте мир:

```bash
source /opt/ros/jazzy/setup.bash
gz sim world.sdf
```

Для движения нажмите Play в Gazebo. Затем во втором терминале Ubuntu перейдите в эту же папку и выполните:

```bash
source /opt/ros/jazzy/setup.bash
python3 simulation.py
```

Скрипт управления подключается к открытому миру. Тип траектории, её размер и время движения можно изменить в `trajectory.py`. Файл `world.sdf` и папку `assets/` нужно держать рядом.

Контакт роликов в этой модели упрощён. Точность реального робота нужно проверять отдельно. Запуск окна и обновлённого управления после изменений не проверен в Gazebo.
